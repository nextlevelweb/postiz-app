Content Studio bundled render fonts
===================================

NotoSans-Regular.ttf and NotoSans-Bold.ttf are unmodified files of Noto Sans
2.015 (unhinted TrueType), licensed under the SIL Open Font License 1.1. The
license is in OFL.txt next to this file and must be kept with the fonts.

Source: the official Noto release
  https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015

  (the same checksum Homebrew's font-noto-sans cask pins for that file)

The renderer pins the font hashes (design.render.default.font.ts) and refuses
any other bytes. To update a font, replace the file and its pinned hash in the
same change; a new file draws text differently.
